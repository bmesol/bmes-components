The `ShareLink` component allows users to easily share a URL across popular social media platforms and messaging apps.

## Props

| Props | Type   | Required | Description                                 |
| ----- | ------ | :------: | ------------------------------------------- |
| url   | string |   Yes    | A string representing the URL to be shared. |
| color | string |    No    | The color of the icon.                      |
